# Project-Portfolio

Luke Chipman's personal engineering project portfolio. The site is a static, responsive page that highlights capabilities, featured work, and experience.

## Structure
- `index.html` — main page for the portfolio site.
- `assets/css/style.css` — styles, responsive layout, and theming.


## Running locally
Open `index.html` in a browser or serve the folder from a simple HTTP server (for example, `python -m http.server 8000`) and visit `http://localhost:8000`.

## Customizing
- Update text content in `index.html` for new projects or contact links.
- Adjust colors or spacing in `assets/css/style.css`.
